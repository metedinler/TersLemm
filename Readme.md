# Ters Lemmings Oyunu

Bu oyun Lemmings'in tersine çevrilmiş versiyonudur. Oyuncu tuzaklar kurar, AI sürü karar verir.

## Özellikler

- Çok katmanlı harita
- Zincirleme ajan hareketi
- Duygu matrisi ile AI
- Oyuncu araçları (mancınık, taş vb.)
- Kazanma/kaybetme koşulları

## Kurulum

1. Python 3.12+ kurun.
2. `pip install pygame`
3. `python main.py` ile çalıştırın.

## Kontroller

- Fare: Alet yerleştir
- Yukarı/Aşağı ok: Katman değiştir
- ESC: Çıkış
